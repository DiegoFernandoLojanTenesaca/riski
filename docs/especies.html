Todo lo que Riksi sabe reconocer.

Cada ficha lleva el nombre con el que se conoce a la especie, su nombre científico y cuántas fotos vio el modelo para aprenderla. Las que tienen pocas son también las que peor identifica.

Las fotografías pertenecen a sus autores, con licencia CC0 o CC-BY 4.0. Provienen de GBIF y de iNaturalist, y aquí se muestran reducidas. El nombre en español viene del listado de nombres vernáculos de GBIF, que no lo tiene para todas.
